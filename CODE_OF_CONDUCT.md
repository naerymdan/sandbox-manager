# Code of conduct

Be civil and be useful. This project is small and run by one maintainer, so the
rules are short.

- Assume good faith, criticize the code and not the person, and keep discussion
  on the technical point.
- No harassment, discrimination, personal attacks, or publishing someone's
  private information.
- Do not post secrets, tokens or private addresses in issues; redact them.

The maintainer may edit or remove comments, close issues and pull requests, and
block users who do not follow this. Report a problem by emailing the address on
the maintainer's GitHub profile, or by using GitHub's report-content feature.
